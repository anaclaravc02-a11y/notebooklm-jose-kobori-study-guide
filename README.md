# notebooklm-jose-kobori-study-guide
Projeto desenvolvido no Bootcamp da DIO utilizando Inteligência Artificial no NotebookLM para criar um caderno temático sobre José Kobori. O repositório reúne curadoria de fontes, engenharia de prompts, testes práticos e um miniguia de estudos focado em educação financeira, investimentos e desenvolvimento pessoal.
## Tecnologias
- NotebookLM
- GitHub
- chat gpt

## Objetivos
- Aprendizagem ativa
- Engenharia de prompts
- Educação financeira
